# RS-31_Evtushenko_Volodymyr_RTOS_LR5
Номер групи: РС-31

Автор: Євтушенко Володимир

ОПЕРАЦІЙНІ СИСТЕМИ РЕАЛЬНОГО ЧАСУ ТА 32 БІТНІ МК Лабораторна робота 5 Програмування АЦП для реалізації функціонального вузла
радіотехнічної системи

Обладнання: STM32F411, CubeIDE.

Мета: Ознайомитися з принципами роботи аналого-цифрового перетворювача STM32F411,
його характеристиками та реалізувати програму для зчитування аналогових сигналів у режиміреального часу.

Завдання до лабораторної роботи:

Варіант 5. Зчитати сигнал з каналу АЦП (PA5), перетворити його у напругу та відображати
на світлодіоді PD13: якщо напруга > 1.7 В — світить, інакше вимкнений.

Функціонал: Зчитує аналогове значення з каналу ADC1 (Channel 5) та порівнює його з порогом.
Якщо значення перевищує 2110, вмикається світлодіод на PB12, інакше — вимикається.
Опитування виконується кожні 100 мс.

Підключення: LED: GND → LED → резистор 220 Ом → PB12

Аналоговий вхід:
Один край → 3.3V
Другий край → GND
Середній вивід → PA5 (ADC_CHANNEL_5)
